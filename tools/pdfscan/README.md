# スキャンPDFを画像に戻す（会議資料を読むための道具）

本部から来る会議資料は**コピー機（RICOH MP C4504）でスキャンしたPDF**で、
文字データが1つも入っていない。中身は 4048×5732・1bit の CCITT G4（FAX）画像が
1ページ1枚。ブラウザもこの形式を表示できないので、アプリ側の PDF取込
（`src/import/pdfText.js`）は「文字が入っていません」で正しく止まる。

ここに置いてあるのは、その画像を人が読める形に戻すための道具。
数字を起こすのは人（またはAI）の目でやる。**自動でOCRはしない**
（1文字の読み違いがそのまま経費の数字になるため）。

外部ライブラリは使わない。poppler も PIL も無い環境で動く。

## 使い方

```bash
# 3ページ目（0始まり）を1/4に縮小してPNGにする
python3 tools/pdfscan/dec.py 会議資料.pdf 2 4 page3.png

# 一部だけ原寸で切り出す（x0 y0 x1 y1）
python3 tools/pdfscan/dec.py 会議資料.pdf 2 1 crop.png 150 0 1250 5732
```

**必ず回してから読むこと。** 資料は横向きにスキャンされていて、そのままだと
行と列が90度ずれる。実際にこれで1行ずれて読み、地代家賃を取り違えた。

```python
import sys; sys.path.insert(0, "tools/pdfscan")
from dec import images
from ccitt import decode_g4
from imgtool import rotate_cw, crop_scale, write_gray
w, h, data = images("会議資料.pdf")[2]
px, rows = decode_g4(data, w, h)
r, rw, rh = rotate_cw(px, w, rows)          # ← これを忘れない
g, ow, oh = crop_scale(r, rw, rh, (0, 0, rw, rh), 4)
write_gray("page3.png", g, ow, oh)
```

## 資料のどこに何があるか（店舗別営業実績表）

- 1ページ目: 営業日報・月報（店舗別の売上/出玉/粗利）
- **3ページ目: TOHO池袋の店舗別営業実績表** ← 経費(pl_month)はここ
  - 左の表 = 当月/累計の 総売上高・売上原価・売上総利益・一般管理費・営業利益・経常利益
  - 右の表 = 勘定科目の内訳。列は 予算 / **実績** / 前年実績 / 予算累計 / 実績累計 / 前年実績累計
  - 一般諸経費の並びは 接待交際費・業務委託料・**機械賃借料・地代家賃・消耗品費**・… の順。
    ここは1行ずれやすい（地代家賃は4,000で固定、消耗品費は数百）
- 4ページ目: 店舗別収支実績集計表（4店舗ぶん）
- 5ページ目: 遊技機入替実績

## 読んだあと必ず検算する

合わなければ読み違い。実際にこの検算で誤読を捕まえている。

- 人件費＋販売費＋建物管理費＋公共料金＋一般諸経費＋減価償却費 ＝ 一般管理費
- 総売上高 − 売上原価 ＝ 売上総利益
- 売上総利益 − 一般管理費 ＝ 営業利益
- 各セクションの明細の合計 ＝ そのセクションの小計
