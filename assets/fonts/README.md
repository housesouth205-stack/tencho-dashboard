# 同梱フォント

## PixelMplus12-Regular.ttf

ドラクエ風テーマ（`assets/css/theme-dq.css`）で使うドットフォント。

- 著作: Copyright (C) 2013 M+ Font Project（PixelMplus: itouhiro）
- 収録: 7,251字（JIS第1・第2水準の漢字6,356字、かな、半角カナ、全角英数記号）
- 生1.27MB。GitHub Pagesはgzip配信なので実際に飛ぶのは**約402KB**

### 使うときの寸法: 24pxか36pxだけ

名前は「12」だが、**12pxでは滲む**。設計サイズだからと12pxを選ばないこと。
`crisp-test.html` で全サイズを実測した結果:

| サイズ | 文字の中の中間調（アンチエイリアスの灰色） | 判定 |
|---|---|---|
| 12px | 50.6% | 滲む |
| 16px | 65.0% | 滲む |
| 20〜23px | 53〜62% | 滲む |
| **24px** | **1.5%** | **くっきり** |
| 25px / 30px | 50.8% / 37.0% | 滲む |
| **36px** | **0.7%** | **くっきり** |
| 48px | 16.9% | 滲む |

PCでは本文24px・見出し36pxに固定している。

### スマホは12px（滲まない）

**滲むかどうかを決めるのはCSSのpxではなく「実際の画素」。**
スマホは1CSSピクセルが2〜3画素なので、CSS12pxは実機で24px（2倍端末）または
36px（3倍端末）で描かれる。どちらもこのフォントが等倍で出るサイズなので、
**PCの24pxと同じだけくっきりしたまま、文字だけ半分にできる。**

倍率別に測り直した結果（`crisp-test.html` は `devicePixelRatio` を掛けて測る）:

| 端末の倍率 | くっきり出るCSSサイズ |
|---|---|
| 1倍（PC） | 24 / 36px |
| 2倍（スマホ） | 12 / 18 / 30 / 48px |
| 3倍（スマホ） | 8 / 12 / 20 / 28 / 32 / 48px |

**本文に使えるのは2倍と3倍の両方に入る12pxだけ。** 見出しは共通のサイズが無いので、
`min-resolution` で出し分けている（2倍→18px、2.5倍以上→20px）。

この対応でスマホの1画面に入る表の行数が2行→8行に戻った。

### 高精細なPCも同じ理屈で小さくできる

倍率2倍のPC（MacのRetina、Windowsの拡大表示200%）はスマホと同じ条件なので、
**画面の文字（見出し・タブ・ボタン・ラベル）を12pxまで落とせる**。
数字は読み違えると困るので、表と等幅数字（`.mono`）だけ18px（＝実機36画素）に戻している。

**倍率1倍のPCでは24pxが最下限。** 12〜23pxをすべて実測したが全滅なので、
この画面では見出しを36→24pxに詰めるところまでしかできない。
それ以上小さくしたい場合は滲みを受け入れることになる。

**フォントを差し替えるときは、必ず `crisp-test.html` を倍率1・2・3で回してこの表を取り直すこと。**
「設計サイズ＝きれいに出るサイズ」とは限らないし、PCで測った表はスマホには使えない。

### 選択カーソルについて

DQの `▶` はCSSの三角形（border）で描いている。PixelMplus12には `▶` が収録されているが、
フォントを差し替えるたびに収録の有無を調べ直したくないので、文字には頼らない。

## 採用しなかったもの

**美咲ゴシック第2**（門真なむ氏 / https://littlelimit.net/misaki.htm）を先に試した。
8×8ビットマップで16pxでくっきり出るため、**スマホの1画面に入る量はこちらが倍近い**
（390px幅で表が約6行 vs PixelMplus12の2行）。ただし字が粗く、漢字の画がつぶれる。

「スマホで見ることは少ない」という運用のため PixelMplus12 を採用した。
**スマホ中心の運用に変わったら、この判断は見直す価値がある。**
