# 同梱フォント

## PixelMplus12-Regular.ttf — PixelMplus12（採用中）

ドラクエ風テーマで使うドットフォント。

- 著作: Copyright (C) 2013 M+ Font Project（PixelMplus: itouhiro）
- 収録: 7,251字（JIS第1・第2水準の漢字6,356字、かな、半角カナ、全角英数記号）
- `▶` `◀` を収録している

### 使うときの寸法

**24pxか36px以外では滲む。** 実測した結果:

| サイズ | 文字の中の中間調 | 判定 |
|---|---|---|
| 12px | 50.6% | 滲む |
| 16px | 65.0% | 滲む |
| 20〜23px | 53〜62% | 滲む |
| **24px** | **1.5%** | **くっきり** |
| 25・30px | 37〜51% | 滲む |
| **36px** | **0.7%** | **くっきり** |
| 48px | 16.9% | 滲む |

名前は「12」だが**12pxそのものでは滲む**。設計サイズだからと12pxを選ばないこと。
測定は `crisp-test.html`（アンチエイリアスの灰色画素が文字に占める割合を数える）。

本文24px・見出し36pxに固定してある。小さめの指定もすべて24pxへ引き上げる。

### 転送量

生1.27MB。GitHub Pagesはgzip配信なので実際に飛ぶのは**約402KB**。

## misaki_gothic_2nd.ttf — 美咲ゴシック第2（未使用）

先に試したフォント。**現在どこからも参照していない。** PixelMplus12で確定したら削除する。

- 著作: Copyright (C) 2002-2021 Num Kadoma（門真なむ）
- 配布元: https://littlelimit.net/misaki.htm
- 8×8ビットマップ。**8の倍数（8/16/24/32px）でくっきり**出る
- 生1.2MB / gzip後 約246KB
- `▶` を**収録していない**

PixelMplus12より字が粗いかわりに、同じ情報量を約2/3の面積に収められる
（本文16pxで足りるため）。スマホの1画面に入る行数を優先するならこちら。

## 選択カーソルについて

DQの `▶` はCSSの三角形（border）で描いている。PixelMplus12には収録されているが、
フォントを差し替えるたびに収録を調べ直したくないので、文字には頼らない。
