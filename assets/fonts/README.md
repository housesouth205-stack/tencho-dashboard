# 同梱フォント

## misaki_gothic_2nd.ttf — 美咲ゴシック 第2

ドラクエ風テーマ（`theme-dq-proto.html`）で使うドットフォント。

- 著作: Copyright (C) 2002-2021 Num Kadoma（門真なむ）
- 配布元: https://littlelimit.net/misaki.htm
- 収録: 7,173字（JIS第1・第2水準の漢字6,356字、かな、半角カナ、全角英数記号）

### 使うときの寸法

**8×8ピクセルのビットマップが原本。** 8の倍数（8/16/24/32px）以外で表示すると
ドットが滲んで汚くなるので、フォントサイズは必ず8の倍数にする。本文は16px。

`▶` は**収録されていない**。DQの選択カーソルはCSSの三角形（border）で描く。
フォント側に無い字を使うと豆腐（□）になるので、記号を足すときは収録を確認する。

### 転送量

生のTTFは1.2MBだが、GitHub Pagesはgzipで配信するので実際に飛ぶのは**約246KB**。
サブセット化すればさらに減らせるが、fontToolsが作業環境に無いため未実施。

### ライセンスについて

美咲フォントは自由に使える旨が配布元に記載されているが、**このリポジトリは公開されている**ため、
再配布の条件は配布元の記載を一度確認しておくこと。条件が合わない場合は、同梱をやめて
利用者の端末のフォントにフォールバックする（テーマは枠と配色だけでも成立する）。
