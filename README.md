# 店長ダッシュボード

パチンコ・パチスロ店の店長向け業務ダッシュボード（Webアプリ）。

## 機能

- **予実管理** — 年間／月間の計画と実績、達成率・着地見込み・残り必要粗利の可視化
- **設定投入シミュレーター** — 島図上で設定を配置し、粗利・計画比をリアルタイム計算
- **島図** — フロア配置図とヒートマップ（アウト／台売上／台粗利）
- **機種分析** — 機種別・台別の実績ヒートマップとランク付け
- **出玉率管理** — 機種×設定の機械割を管理。同梱の機種データベース（出典URL・信頼度つき）から一括適用でき、無い機種はWebから自動取得

## 機種データベース

`pachislot-db/` に、スマスロ／6号機の出玉率（設定1〜6）とコイン単価を出典付きで集めたデータベースがある。
出玉率管理画面はここから書き出した `src/data/payout-db.json` を読んで、機種名の照合で出玉率を埋める。

- 収録: 572機種（うち出玉率を取得できた559機種を書き出し）
- 取得元: スロベース／ななプレス（設定別の機械割表）、P-WORLD（規則区分・型式名・設置店舗数）、
  DMMぱちタウン・パチ7（機械割のレンジ）
- 更新: `python3 pachislot-db/scripts/export_for_dashboard.py`

詳細と取得ルールは [`pachislot-db/README.md`](pachislot-db/README.md) を参照。

## 技術構成

- フロントエンド: 素のHTML/CSS/JavaScript（ESモジュール、ビルド工程なし）
- バックエンド: Supabase（PostgreSQL + 認証 + Edge Functions）
- 配信: GitHub Pages

## セキュリティ

データはすべてSupabase側で管理し、**Row Level Security により認証済みユーザーのみ**が読み書きできます。
本リポジトリに含まれるのは画面を構成するコードのみで、店舗の営業データは一切含まれません。
公開されている接続キー（publishable key）だけではデータへアクセスできません。

## ローカルでの実行

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。
